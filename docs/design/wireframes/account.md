# Account and team selection

These screens are scoped to the signed-in person. The Platfolio menu opens navigation, the Team selector sets the workspace, and the avatar opens Account and Log out. [Wireframe index](README.md)

## Notification rules

`/dashboard/notifications` · From the user menu

**Desktop**

```text
+--------------------------------------------------------------------+
| Header | Team | Avatar                                             |
| Notifications                                                      |
| +--------------------------------+ +-----------------------------+ |
| | Your rules | Active / Paused    | | Add or edit a rule          | |
| | Event | State | Team / App      | | App scope                  | |
| | Environment | Email            | | Event | Verified email      | |
| | Edit | Pause / Resume | Remove | | Save                        | |
| +--------------------------------+ +-----------------------------+ |
|                                    | Email delivery settings     | |
+--------------------------------------------------------------------+
```

**Mobile**

```text
+--------------------------------------+
| Header | Team | Avatar               |
| Notifications                        |
| [Your rules | Edit | Pause | Remove] |
| [Add or edit a rule]                 |
| [Team | App | Environment | Event]   |
| [Verified email | Save]              |
| [Email delivery settings]            |
+--------------------------------------+
```

Choose an event for one app on a team you belong to. A rule can cover one environment or all environments. Use your team or account default, or select another verified address. Password and key update notifications identify the setting that changed. The mockup saves rules for the session and simulates delivery preferences.
